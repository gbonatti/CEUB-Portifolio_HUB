### 🌐 Projeto Internacional — Priority Project C21 (DWD)
**2018 – 2022 | Colaboração Internacional**

Participação na **transição do modelo COSMO para ICON**, um dos maiores projetos de modernização da previsão numérica da Europa. A contribuição brasileira consistiu na calibração e validação do novo modelo para a América do Sul.

### 🔄 Assimilação de Dados 3DVAR + MBAR
**INMET | Pesquisa Aplicada**
